# ایزوگام پارسی | Izogam Parsi

وب‌سایت شرکتی ایزوگام پارسی با هدف معرفی محصولات، خدمات و ایجاد بستری برای ارتباط آسان‌تر مشتریان با مجموعه توسعه داده شده است.

## معرفی پروژه

این پروژه یک وب‌سایت چندصفحه‌ای شرکتی است که با استفاده از **Next.js** پیاده‌سازی شده و شامل بخش‌های مختلفی برای معرفی مجموعه، محصولات، خدمات و انتشار مقالات است.

در فرایند توسعه این پروژه، از ابزارهای هوش مصنوعی به‌عنوان دستیار برنامه‌نویسی برای تولید، بهبود و اصلاح کدها استفاده شده است. همچنین ساختار پروژه و خروجی نهایی مورد بررسی و تنظیم قرار گرفته‌اند.

## امکانات و بخش‌ها

- صفحه اصلی
- معرفی محصولات
- معرفی خدمات
- درباره ما
- مقالات و مطالب آموزشی
- تماس با ما
- فرم ثبت سفارش

## تکنولوژی‌های استفاده‌شده

- **Next.js** – توسعه ساختار و صفحات وب‌سایت
- **React** – پیاده‌سازی رابط کاربری مبتنی بر کامپوننت
- **HTML5** – ساختاردهی صفحات
- **CSS3** – طراحی و استایل‌دهی
- **AI-Assisted Development** – استفاده از ابزارهای هوش مصنوعی در فرایند توسعه و بهبود کد

## ویژگی‌های فنی

- طراحی چندصفحه‌ای
- رابط کاربری واکنش‌گرا (Responsive Design)
- استفاده از کامپوننت‌های قابل استفاده مجدد
- خروجی استاتیک (Static Export)
- انتشار روی دامنه اختصاصی

## نقش هوش مصنوعی در توسعه پروژه

این وب‌سایت با کمک ابزارهای هوش مصنوعی توسعه داده شده است. از این ابزارها برای تسریع فرایند کدنویسی، تولید بخش‌هایی از رابط کاربری، پیشنهاد راهکارهای فنی و اصلاح کدها استفاده شده است.

این تجربه فرصتی برای آشنایی عملی با فرایند توسعه یک وب‌سایت واقعی و کار با Next.js در کنار ابزارهای مبتنی بر هوش مصنوعی فراهم کرد.
